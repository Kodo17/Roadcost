ROADCost — instalare gratuită

1. Încarcă toate fișierele din acest folder într-un repository GitHub public.
2. În GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
3. Așteaptă publicarea și deschide adresa GitHub Pages în Safari pe iPhone.
4. Apasă Share (pătratul cu săgeată) > Add to Home Screen > Add.

Aplicația este o PWA statică. Nu necesită abonament, server sau cont.
Datele se salvează local în browserul/dispozitivul curent. Exportă periodic backup din Rapoarte.
Nu șterge datele Safari dacă vrei să păstrezi înregistrările locale.
Pentru actualizări, înlocuiește fișierele din repository.

Funcții: garaj multi-mașină, jurnal alimentări, cheltuieli, calculator de drum, buget lunar, backup/import JSON.
